# Брендбук (рабочий, нейтральный) — NordSea Export

> Фирменного брендбука у заказчика нет. Стиль создан нейтральным и аккуратным;
> при получении брендбука клиента меняются только CSS-переменные и логотип.

## 1. Логотип

- Файл: `info/logo.svg` (тёмная версия для обложек), `public/img/logo.svg` (шапка), `public/img/favicon.svg`.
- Знак: рыба + волна, текст «NORDSEA EXPORT». Легко заменяется на фирменный знак.

## 2. Палитра

| Роль | Цвет | HEX |
|---|---|---|
| Основной (шапка, футер, заголовки) | Глубокий синий | `#0B2E4F` |
| Фон секций | Ледяной белый | `#F5FAFD` / `#EAF4FA` |

## 3. Типографика

- Шрифт: **Inter** (fallback: Segoe UI, Arial, sans-serif).
- H1 — 36–44 px / 700; H2 — 28 px / 700; H3 — 20 px / 600; текст — 16 px / 400; подписи — 13–14 px.
- Межстрочный интервал 1.5, заголовки 1.2. Выравнивание по левому краю.

## 4. Стиль интерфейса

- «Холодный» деловой экспортный стиль: много воздуха, крупные заголовки, карточки со скруглением 10–12 px и мягкой тенью.
- Кнопки: залитые акцентом, радиус 10 px; вторичные — контурные.
- Фото продукции — холодные тона; в MVP используются плейсхолдеры с иконкой категории (заменяются на реальные фото).
- Цены не указываются: «Price on request / Цена по запросу».
- CTA: «Отправить запрос / Send inquiry».
- Запрещено: кричащие цвета, кислотные градиенты, 3D-стоковые иконки, более двух акцентов на экране.

## 5. Тон текстов

- Деловой, конкретный, без превосходных степеней («надёжный поставщик», а не «лучшие в мире»).
- Пишем о фактах: спецификации, партии, документы, логистика, сроки ответа (1 рабочий день).
